# Объектно-ориентированное программирование

## SyllableSplitter

Консольная программа, которая разбивает введённое русское слово на слоги. Функция реализована в двух вариантах: для `std::string` и для C-строк (`const char*`) с ручным управлением памятью.

## LogicElement

Модель логического элемента с входными и выходными клеммами. Класс `Terminal` описывает клемму (тип, число соединений, сигнал `0`/`1`/`X`), класс `LogicElement` хранит динамические массивы клемм, которые расширяются при добавлении. Реализованы конструкторы копирования и перемещения, соответствующие операторы присваивания, доступ по индексу, соединение элементов оператором `>>`, ввод и вывод через потоки и ASCII-отрисовка элемента. Код документирован в формате Doxygen и покрыт тестами на Catch2.

Зависимости: Catch2 версии 2.

## BrigadeSimulator

Симуляция работы бригады на строительных участках. В бригаде есть рабочие, мастера и бригадир, между людьми бывают дружба и вражда, которые влияют на производительность. Можно создавать участки с объёмом работ, назначать на них людей, повышать рабочих до мастеров, моделировать рабочие дни и искать самый проблемный участок. Состояние бригады сохраняется в файл и загружается из него.

Что использовано в проекте:

- архитектура **MVP** (Model–View–Presenter) со слоями репозиториев, сервисов, DTO и мапперов;
- паттерн **Strategy** для повышения рабочего до мастера;
- собственная шаблонная **хеш-таблица** с итераторами и концептами C++20;
- **многопоточная** симуляция рабочего дня с замером времени в сравнении с однопоточной версией;
- сохранение и загрузка состояния в **YAML**;
- модульные тесты на **Google Test** (81 тест).

Зависимости: yaml-cpp, Google Test.
